# Dragon Ball Xenoverse 2 Archipelago Manual
An Archipelago Randomizer Manual adaptation of the Dragon Ball Xenoverse 2 Game. This manual can be played from both a new save file, or a save file with multiple characters.

All game information can be found below.

## What is considered a location check in DBXV2?
Location checks can be sent whenever you finish a battle in the story mode, not a specific time patrol that you go out on, just the seperate battles in those time patrols. Checks also include all 90 Parallel Quests that are doable BEFORE the completion of the base game.

## When the player receives an item, what happens?
When the player receives an item, they either get ability slots, item stots, Transformations, Scrolls of Time, or Progressive Star PQ Unlocks.

A two main items are required for progression in the game, these items are:
- **Scrolls of Time:** Required throughout the story mode of the game to unlock the next "arc" in the game, for example, if you have no scrolls of time, you can do the full Saiyan Saga, if you have 1 scroll of time, you can do the Namek Saga, etc.
- **Progressive Star PQs:** These let you do all the parallel quests that have a specific star of difficulty, for example, if you have none of these, you can do 1 star PQ's only, if you have 1 of these, you can do 2 star pqs, and all the way up to 7 star.

## What are the available options?

Currently, there are no real options besides Deathlink, which will show up on your manual tracker at the top right and tell you to die, or let you send deathlinks. There will be more options in the future versions.

## What about XV2 Mods and DLC?

Mods and DLC can be used, though the DLC Story and DLC Parallel Quests are not included in this Manual.

## Save File Info

It is recommended that you use a save file with a character that has almost if not everything unlocked, so you can start using the transformations and skills immediately when you get them in the archipelago. This is obviously not required.
